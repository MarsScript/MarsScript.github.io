Eclipse Patch Notes • v1.7.2

v1.7.2 — New Database Connected & WebP Storage LATEST
  • Connected a New Database: Migrated Eclipse onto a fresh, high-speed Supabase database so chats, accounts, and DMs run smoothly again.
  • Low-Egress Optimization & HD WebP Media: Upgraded image compression to high-resolution WebP and tuned background sync intervals to prevent future quota limits.

v1.7.1 — Free Database Quota Reached

The previous free Supabase database ran out of its monthly egress/data quota, temporarily pausing old database requests until migration.

v1.7 — Admin Email 2FA & Account Password Changer

  • Admin-Only Email Verification: Admin account logins now trigger a 6-digit security verification code sent via Brevo to the owner email before granting access, while standard members sign in without email prompts.
  • Working Change Password: Added a dedicated Change Password section inside Profile → Settings so users can securely update their account password directly in the database.

v1.6.2 — UI Remake, 6th Support/Admin Tab & Auto-Mod

Introduced the 6-tab navigation shell, 10 custom themes, Feed clips, DMs, Friends system, and Admin audit logs.
