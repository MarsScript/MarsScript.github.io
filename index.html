Eclipse Patch Notes

Full update history & version changelog

LATEST — v4.0 Social & Feed Update Nov 2026
  • TikTok-Style Profiles & Bio: Added customizable user bios (up to 400 characters) with posts displayed directly beneath your bio.
  • Display Names & 3-Day Cooldown: Set custom display names while keeping your @username handle permanent (can be changed once every 3 days).
  • Clickable Global Chat Profiles: Tap any username or avatar in Global Chat to open their profile, follow them, or send a friend request directly.
  • New Feed Tab (Images & Videos): Upload photos or short videos with captions, plus full Likes, Favorites, Comments, and Followers/Following counts.
  • Admin Moderation Powers: Admins (Fareed & TestBot) can delete posts/videos and ban accounts directly from user profiles.
  • Patch Notes Modal: Added this scrollable update history with gray backdrop mask.
v3.2 — Photo Sharing & Zero-Flash Sync
  • Added photo attachments & full-screen lightbox viewer inside both Global Chat and Direct Messages.
  • Granted automatic Admin moderation privileges to the Fareed account.
  • Implemented message signature diffing to eliminate chat feed flashing during live sync.
v3.0 — Instant Profile Pictures (PFPs)
  • Added instant Profile Picture (PFP) uploads with automatic 160x160 JPEG center-crop compression and cloud sync (no verification queue required).
  • Preserved deterministic colored initial letter badges as automatic fallbacks.
v2.0 — iPad Safari Compatibility & GitHub Pages
  • Replaced sandbox-restricted WebSockets with a rock-solid REST polling engine for seamless Safari & iPad performance on MarsScript.github.io.
  • Added Roblox-style newest-first message stacking, Group Chats, and the Friends request system with green ✓ / red ✕ buttons.
v1.0 — Original Eclipse Launch
  • Initial release featuring the classic Eclipse circular logo badge, dark slate glassmorphism UI, case-insensitive username login, and Global Lounge chat.
